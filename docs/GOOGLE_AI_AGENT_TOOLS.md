# Google AI Agent Tools

Read-only tools: `get_customer_360`, `get_card_transaction`, `get_payment_status`, `get_collection_status`, `get_mobile_banking_status`, `get_fraud_alerts`, `get_investment_portfolio`. Call the documented HTTPS GET endpoints with `X-API-Key`, `X-Correlation-ID`, and `X-Google-AI-Session-ID`. Do not expose legacy write endpoints to the agent. Treat offers as demo recommendations, never financial advice or credit decisions.
