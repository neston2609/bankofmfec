# Genesys Integration

Configure Data Actions with `X-API-Key` and forward `X-Correlation-ID` plus `X-Genesys-Conversation-ID`. Recommended GET actions: `/api/customers/search?q=`, `/api/customers/{id}/360`, `/api/customers/{id}/kyc`, `/api/cards/{id}/transactions`, `/api/customers/{id}/mobile-banking`, `/api/customers/{id}/payments`, `/api/customers/{id}/offers`. Genesys remains responsible for voice, Architect, bots where suitable, queues/routing, digital, outbound and analytics.
